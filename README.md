# 🍱 Обед — кто не ест

Офисный сервис: каждый день человек один раз отмечает, что **не будет обедать** — его порцию от кейтеринга может забрать любой коллега. Порция не пропадает.

## Как работает

1. Открой сайт на телефоне → введи имя (запоминается)
2. Не обедаешь сегодня? Нажми **«Я сегодня не обедаю»** — один раз в день
3. Голоден? Смотри раздел **«Свободные порции»** → жми **«Заберу»**
4. Передумал? Отмени отметку или верни порцию

Каждый день — новый список (автосброс по дате, TZ Asia/Baku).

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/today` | состояние на сегодня: свободные порции, разобранные, известные люди |
| POST | `/api/skip` | `{name}` — отметить «не обедаю» (идемпотентно) |
| POST | `/api/unship` | `{name}` — снять отметку (409 если порцию уже забрали) |
| POST | `/api/claim` | `{from, by}` — забрать порцию (409 если уже забрана) |
| POST | `/api/unclaim` | `{from, by}` — вернуть порцию (только забравший) |

Имена валидируются (только буквы/цифры/пробел/дефис/апостроф/точка, ≤40 символов).

## Запуск

```bash
npm install
npm start        # порт из $PORT или 3000
```

Переменные окружения: `PORT`, `DB_PATH`, `TZ` (по умолчанию Asia/Baku).

## Стек

Node.js + Express + better-sqlite3 (SQLite), статический mobile-first фронтенд на ванильном JS.
