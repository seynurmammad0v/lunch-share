# 🍱 Обед — кто не ест

Офисный сервис: каждый день человек один раз отмечает, что **не будет обедать** — его порцию от кейтеринга может забрать любой коллега. Порция не пропадает.

## Как работает

1. Открой сайт с телефона → введи имя (запоминается)
2. Не обедаешь сегодня? Нажми **«Я сегодня не обедаю»** — один раз в день
3. Голоден? Смотри раздел **«Свободные порции»** → жми **«Заберу»**
4. Передумал? Отмени отметку или верни порцию

Каждый день — новый список (автосброс по дате, TZ Asia/Baku).

**Идентификация — по телефону (device_id), не по имени.** Имя — только отображаемое, его можно менять: забрать свою же порцию под другим именем невозможно (сервер проверяет device). Отменить отметку можно только со своего телефона.

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/today?device=&name=` | состояние на сегодня + `me` (моя отметка и мои заявки) |
| POST | `/api/skip` | `{device, name}` — отметить «не обедаю» (идемпотентно) |
| POST | `/api/unship` | `{device}` — снять отметку (409 если порцию уже забрали) |
| POST | `/api/claim` | `{device, name, from}` — забрать порцию (400 self_claim если своя, 409 если уже забрана) |
| POST | `/api/unclaim` | `{device, from}` — вернуть порцию (только забравший телефон) |

`device` — уникальный ID телефона (UUID в localStorage). Имена валидируются (только буквы/цифры/пробел/дефис/апостроф/точка, ≤40 символов).

## Запуск

```bash
npm install
npm start        # порт из $PORT или 3000
```

Переменные окружения: `PORT`, `DB_PATH`, `TZ` (по умолчанию Asia/Baku).

## Стек

Node.js + Express + better-sqlite3 (SQLite), статический mobile-first фронтенд на ванильном JS.
